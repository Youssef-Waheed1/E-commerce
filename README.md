## 1. One-line description
Handmade bead bag storefront and admin dashboard for browsing, ordering, and managing products and reviews.

## 2. Tech stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- @supabase/ssr
- Lucide React
- clsx
- tailwind-merge

## 3. Key features
- Product catalog with search and filters for bags
- Shopping cart with quantity updates and WhatsApp checkout
- Customer review form with star ratings, CAPTCHA, and moderation status
- Admin login and dashboard for bags, reviews, analytics, and settings
- Supabase-backed data loading for store settings, products, and reviews

## 4. Run steps
1. Install dependencies:
   npm install
2. Set required environment variables:
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_ANON_KEY
3. Start the app:
   npm run dev
4. Open the local app in a browser at:
   http://localhost:3000
